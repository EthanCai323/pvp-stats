# PvP Stats（Minecraft 1.21.7 Fabric 服务端 Mod）

PVP 组别战绩统计模组：创建 PVP 组、可点击的邀请/结束请求、K/D 计分板、自动结束与战报日志。**纯服务端**，客户端无需安装。

## 功能

- `/pvp start <名称>` —— 创建 PVP 组别，侧边计分板显示 `PVP:组名` 与每位成员的 K/D
- `/pvp add <组名> <玩家>` —— 发送邀请，对方在聊天栏点击 **[接受]** / **[拒绝]**
- `/pvp quit <组名>` —— 退出组别（战绩在组别存续期间保留，再次被邀请可恢复）
- `/pvp end <组名>` —— 发起结束请求，需**所有成员**点击 **[同意]** 才解散
- 组内成员只能攻击同组玩家；组外玩家无法攻击组内成员
- 仅剩 1 人持续 30 秒或组内无人时自动结束
- 结束后聊天框公布战绩，并在服务器目录 `pvplogs/` 生成以开始时间命名的战报文件（如 `20260825162324.txt`），包含组别名、每人 K/D、两两击杀明细与全部死亡记录
- 掉线 1 分钟内重连保留组别与战绩
- 组名全局唯一，一名玩家同时只能加入一个组别

## 环境（本分支：MC 1.21.11）

- Minecraft 1.21.11（1.21.7 版本见 `main` 分支）
- Fabric Loader ≥ 0.16.0
- Fabric API（如 0.141.6+1.21.11）
- Java 21

## 构建

```bash
gradlew build
```

产物位于 `build/libs/pvp-stats-<版本>.jar`，放入服务端 `mods` 文件夹即可。
